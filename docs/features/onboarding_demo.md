# 引导页与示例资源包

## 基本信息

| 字段 | 内容 |
| --- | --- |
| 功能 ID | `onboarding.demo_pack` |
| 当前状态 | 部分实现 |
| 主要入口 | `/onboarding` |
| 目标用户 | 第一次使用伴学的新用户 |

## 功能目标

让新用户不需要先准备教材，也能体验完整学习链路：创建科目、导入示例资料、进入科目空间、生成思维导图和讲义，并继续进入练习、错题和计划。

## 用户流程

1. 用户首次打开应用进入引导页。
2. 引导页展示核心功能。
3. 用户选择体验示例资源包。
4. 如果未登录，系统记录待执行任务，登录后继续。
5. 系统创建示例科目。
6. 系统导入示例资料。
7. 用户进入科目空间查看资料、导图和讲义入口。

## 技术结构

| 层级 | 文件 | 说明 |
| --- | --- | --- |
| 页面 | `lib/features/onboarding/onboarding_page.dart` | 引导页 |
| 服务 | `lib/features/onboarding/onboarding_demo_service.dart` | 示例科目和资源创建 |
| Shell | `lib/features/home/responsive_shell.dart` | 登录后执行待处理示例任务 |

## 行为边界

- 示例资源包应有版本号，避免重复导入。
- 示例资料来源必须清晰，不能混入版权不明材料。
- 如果导入失败，应允许用户跳过引导继续使用应用。

## 后续计划

- 将示例资源包做成可版本化资产。
- 增加不同学段/科目的示例包。
- 导入后自动触发导图和讲义生成。
- 在引导页展示真实生成结果，而不是只展示功能介绍。
