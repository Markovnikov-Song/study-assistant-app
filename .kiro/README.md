# .kiro 历史规格说明

`.kiro/specs/` 中的文件是历史设计、需求、任务和修复记录，不再作为当前项目的事实来源。

请 AI 或新协作者优先阅读：

1. `docs/README.md`
2. `docs/reconstruction_guide.md`
3. `docs/project_blueprint.md`
4. `docs/inventory/*.md`
5. `docs/features/feature_manifest.json`
6. `docs/features/*.md`

`.kiro` 的使用规则：

- 可以作为历史灵感和需求来源。
- 不能直接把 `.kiro` 中的“已实现”“将实现”“任务完成”视为当前事实。
- 不能直接按 `.kiro` 中旧路由、旧表名、旧 Agent 名称或旧占位接口实现功能。
- 如需复用 `.kiro` 内容，必须先对照当前代码和 `docs/legacy_document_audit.md`。

当前权威文档入口是 `docs/README.md`。
